# WorkSphere Frontend

Frontend thiết kế lại cho hệ thống quản lý dự án, công việc và nhân sự doanh nghiệp.

## Công nghệ

- React 18, TypeScript, Vite, Tailwind CSS
- Zustand, Axios, React Hook Form + Zod
- Recharts và Lucide React
- Mock API/localStorage dùng chung với frontend cũ để bảo toàn luồng P0

## Chạy local

```text
npm install
npm run dev
```

Tài khoản demo dùng mật khẩu `demo123`: `admin@demo.local`, `leader@demo.local`, `reviewer@demo.local`, `assignee@demo.local`, `follower@demo.local`.

## Kiểm tra

```text
npm run test:p0
npm run build
```
